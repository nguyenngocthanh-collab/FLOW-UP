# Session Packets

Create one folder per bounded chat task. Each packet should include:
- `SESSION_PACKET.md`
- the exact skill file(s)
- Master Blueprint and Current Status
- assigned module overview
- assigned child specs
- relevant contracts and dependency entries
- relevant ADRs

For ChatGPT web, attach these files to the new chat. A folder in GitHub/local storage is not automatically visible to a fresh chat.

Use the starter prompts in `PROMPTS.md`.
