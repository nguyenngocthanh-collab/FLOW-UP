**ID:** MOD-03-REQ-001  
**Parent:** MOD-03  
**Version:** 0.1

## Purpose
Capture testable requirements for Goal Management.

## Draft user stories
- As a user, I can create a goal inside a project.
- As a user, I can edit a goal's title and description.
- As a user, I can organize goals with parent-child hierarchy.
- As a user, I can view goals in a list.
