# Product Hypotheses & Experiments

| ID | Hypothesis | Experiment | Evidence / metric | Decision rule |
|---|---|---|---|---|
| H-001 | Users understand outcome-first setup | 3-5 users create a goal | Completion rate, help requests, time | Revise if users repeatedly get stuck |
| H-002 | List/Outline is easier than Tree for editing | Same task in both views | Time, errors, preference | Keep Tree only if it adds measurable value |
| H-003 | Progress feedback helps users understand status | Ask users to interpret a progress panel | Correct interpretation, confidence | Simplify if interpretation is poor |
| H-004 | Scheduling actions closes planning-to-execution gap | User schedules a goal action | Successful scheduling, friction | Reduce steps if abandonment occurs |
| H-005 | Measurement history is useful | User updates a metric twice | Return behavior, perceived usefulness | Reassess if users do not understand metric |

Record participants with consent. Do not overgeneralize from a very small sample.
