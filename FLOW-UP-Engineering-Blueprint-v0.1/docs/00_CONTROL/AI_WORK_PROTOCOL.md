# AI Work Protocol

## Before starting a session
- Read Master Blueprint and Current Status.
- Read the assigned skill.
- Read only the relevant requirements/specifications/contracts plus their dependencies.
- Confirm the target branch/commit and allowed scope.

## Task packet required
Every assignment must state:
- Task ID and module ID
- Desired outcome
- Specification and contract versions
- Allowed files/modules
- Forbidden changes
- Dependencies and preconditions
- Acceptance criteria
- Required tests
- Output and handoff format

## Parallel work
- Parallelize only tasks with non-overlapping files and stable contracts.
- One owner controls shared contracts and migrations.
- Do not have multiple sessions edit the same schema, registry, or shared package simultaneously.
- Integrate through reviewed commits/PRs.

## Completion
A task is not complete because code was generated. It is complete when acceptance criteria have evidence, tests are reported, and documentation is reconciled.
